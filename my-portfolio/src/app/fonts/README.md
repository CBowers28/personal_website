# Local fonts

## Advercase

`Advercase-Regular.woff2` — a retro serif display typeface by Indieground Design,
inspired by Apple's Garamond-style advertising lettering from the 80s/90s.

- Free version (letters + numbers + basic punctuation), converted from the
  distributed OTF to WOFF2 for the web.
- Used as the site's primary typeface via `next/font/local` (see
  `src/app/layout.tsx`), exposed as the `--font-advercase` CSS variable.
- Product page: https://indieground.net/product/advercase-font/

If a paid/commercial license is ever required for this site, purchase it from
Indieground and swap the file in place — no code changes needed.
